# MyApp

## Setup

1. Clone the repository: `git clone https://github.com/yourusername/MyApp.git`
2. Install dependencies: `bundle install`
3. Setup the database: `rails db:setup`
4. Start the server: `rails server`

## Features

- User Authentication with Devise
- Profile management with avatar upload, city, state, country, phone, and gender
- Post creation with images and tags
- Commenting on posts
